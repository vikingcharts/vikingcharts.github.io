Secret Knowledge: Third Stage

  • Costs update automatically based on the selected Knowledge Tree and Upgrade Cost Level.
  • The Secret Knowledge Cost Summary section is collapsed by default. Select an Upgrade Cost Level for each Knowledge Tree to calculate the total cost of all Knowledges. The selected upgrade levels are automatically applied to the Knowledge Upgrade Cost per Level section.
  • Knowledge Upgrade Cost per Level section: Each Knowledge Tree shows how many Level 10 and Level 5 upgrades it contains.
  • Select an Upgrade Cost Level for each Knowledge Tree. The cost table updates automatically and displays the cost per Knowledge.
  • Enter how many Knowledges you want to upgrade at each level. The Total and Grand Total update automatically.
  • The badge next to each Knowledge title shows the currently selected Upgrade Cost Level.
